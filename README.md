# Gestor de Tareas CLI

Pequeña aplicación de línea de comandos para añadir, listar y completar tareas desde la terminal. Proyecto de prácticas de 1º de ASIX.

## Objetivos

- Aprender a estructurar un proyecto en Python.
- Practicar el uso de Git y GitHub.
- Documentar el código con Markdown.

## Instalación

Clona el repositorio en tu equipo:

```bash
git clone https://github.com/usuario/gestor-tareas.git
```
